# snake_game# Snake Game 🐍

A classic Snake Game built using Python's `turtle` module. Control the snake, eat food, and grow longer while avoiding collisions with the walls and your own tail. The game ends when the snake collides with itself or the wall.

---

## Features
- **Snake Movement**: Use arrow keys to control the snake's direction.
- **Food**: Randomly appears on the screen. Eating food increases the snake's length and score.
- **Scoreboard**: Displays the current score.
- **Game Over**: Ends the game when the snake collides with the wall or itself.

---

## How to Play
1. Run the `main.py` file to start the game.
2. Use the arrow keys (`Up`, `Down`, `Left`, `Right`) to control the snake.
3. Eat the red food to grow the snake and increase your score.
4. Avoid colliding with the walls or the snake's tail.

---

## Requirements
- Python 3.x
- `turtle` module (pre-installed with Python)
